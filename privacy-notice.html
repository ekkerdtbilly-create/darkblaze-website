Privacy notice

Privacy and visitor information on the DarkBlaze Group website.

Status: owner review required before public launch. This notice describes the current website implementation; hosting-provider logging and retention are not yet verified.

Information handled by this page

The website has no application database, analytics, cookies, browser storage, application-level visitor logs, or automatic interaction/error telemetry. Each visit starts fresh. Pressing “Agree and continue” is the explicit opt-in to enter and receive the browser’s optional location prompt. If allowed, longitude remains in page memory while this page is open to adjust the day/night color profile; closing or reloading the page clears it. The site does not save or transmit longitude, and location can be denied without blocking entry. Your browser may remember its own permission setting, but the website does not persist consent. Live weather is not connected, so the current build does not use location for forecasts. A suitable commercial weather source and updated disclosure are required before that feature can be enabled. No other sensor is requested. Questions entered into the local Site Secretary receive prepared replies in the current page and are not sent or saved by the site.

Contact handoffs

If you choose an email or WhatsApp link, the browser opens your selected app with a draft. Nothing is sent until you review and send it there. The website does not receive the reply or automatically confirm it. A phone link opens the dialer but does not place a call.

Issue reports and information you choose to send

The site does not automatically collect interaction histories or bug telemetry. If you choose to send a bug report or contact request, DarkBlaze can use the details you include to investigate, reply, and fix the reported issue. The website does not receive or retain the email/WhatsApp draft; your chosen app and its provider handle it after you send it.

Connection data and hosting

The website code does not implement application-level IP logging and does not send IP addresses to an analytics service. The web host, CDN, DNS, or network providers may still process connection data such as an IP address, request time, or requested files. DarkBlaze has not verified the final production host’s logging, retention period, or privacy terms. Those infrastructure practices must be reviewed before public launch; this notice cannot promise that no provider records an IP address.

Changes and contact

This notice reflects the static website build as of 5 November 2026. Questions about this notice can be sent to admin@darkblaze.org. No message is sent unless you choose to send it from your email app.

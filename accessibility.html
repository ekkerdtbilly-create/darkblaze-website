DarkBlaze Group · website information

Accessibility statement

Our current accessibility goals, known limits, and a way to report barriers.

Status: initial statement. Automated browser checks have passed for the reviewed build, but manual assistive-technology testing is still outstanding.

Design approach

DarkBlaze aims to support keyboard use, readable contrast, reduced-motion preferences, responsive layouts, and clear control names. Visitors can select Automatic, night, or daytime display. The welcome animation is skipped when reduced motion or supported Data Saver is active. Location-based color adaptation is optional and falls back to the local clock. The website has a static fallback for the ambient animation.

Current limits

Automated accessibility scans do not prove full accessibility. Manual screen-reader, switch-control, zoom, and physical-device checks have not all been completed. Some project diagrams and animated visual material may need additional descriptions.

Report a barrier

Email admin@darkblaze.org with the page and task affected, plus a way to reply if you want one. Your email app opens a draft; you choose whether to send it. Do not include sensitive information unless needed.
